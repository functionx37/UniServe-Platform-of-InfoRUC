# 学业分析模块交接说明

这份说明面向学生端小程序同学和后续接手后端的同学，目标是把“成绩单上传 -> 培养方案比对 -> 未完成模块识别 -> 本学期选课建议”这条链路一次讲清。

## 1. 当前结论

本模块已经复用现有学生端上传入口，不需要小程序新增上传页面或新建重复接口。

当前可直接使用的页面/服务：

- 小程序页面：`miniprogram/pages/transcript-upload/index`
- 小程序服务：`miniprogram/services/file.js`
- 后端接口：`POST /academic/transcript/upload`
- 后端分析接口：`GET /academic/status`
- 后端分析接口：`GET /academic/analysis`

## 2. 当前后端做了什么

### 2.1 成绩单 PDF 解析

对应代码：

- `backend/src/main/java/cn/edu/ruc/info/service/TranscriptParsingService.java`

当前支持：

- Excel 成绩单：`.xls` / `.xlsx` / `.csv`
- 文本型 PDF 成绩单：`.pdf`

本次已基于仓库样例 `file/成绩单示例/示例成绩单.pdf` 适配。

解析结果会写入：

- `transcript_uploads`
- `academic_records`

说明：

- 样例 PDF 去掉了成绩和逐门学分，因此 PDF 解析重点是“识别课程名 + 识别学期”
- 若后续接入真实成绩单且文本布局变化较大，需要继续补 PDF 解析规则
- 扫描版 PDF 目前仍不支持

### 2.2 培养方案结构化

对应代码：

- `backend/src/main/java/cn/edu/ruc/info/service/CurriculumDefinitionParser.java`
- `backend/src/main/java/cn/edu/ruc/info/service/CurriculumService.java`

本次已基于仓库样例 `file/培养方案示例/培养方案示例.xlsx` 适配。

当前会把原始 Excel 解析成更适合程序运行的结构：

- 模块 `requiredModules`
- 规则组 `requirementGroups`
- 课程目录 `requiredCourses`

并在上传培养方案后自动生成一份结构化文件：

- `*.processed.json`

当前支持的规则：

- `必修`
- `任选一门`
- `五选二`
- `至少选修一门`

说明：

- 样例 Excel 没有逐门学分列，所以当前分析主度量是“课程要求单元”
- 如果后续学院提供了标准化“课程+学分+模块最低要求学分”版本 Excel，建议继续补精确学分分析

### 2.3 学业分析结果

对应代码：

- `backend/src/main/java/cn/edu/ruc/info/service/AcademicAnalysisEngine.java`
- `backend/src/main/java/cn/edu/ruc/info/service/AcademicService.java`

当前分析内容包括：

- 总要求 / 已完成 / 缺口
- 模块进度
- 未完成必修课
- 未完成的范围选课规则组
- 当前学期与下学期选课建议
- 成绩单中已匹配课程数
- 成绩单中未匹配到培养方案的课程名

当前时间规则：

- 春季学期：`2-7月`
- 秋季学期：`8月-次年1月`

例如当前日期 `2026-06-07` 会被识别为：

- 当前学期：`2025-2026学年春季学期`
- 下学期：`2026-2027学年秋季学期`

## 3. 小程序同学如何对接

### 3.1 上传接口

- 路径：`POST /academic/transcript/upload`
- 请求方式：`multipart/form-data`
- 文件字段名：`file`
- 当前小程序代码已经这样调用，不需要改字段名

成功返回示例：

```json
{
  "success": true,
  "message": "操作成功",
  "data": {
    "fileId": "file-1234abcd",
    "fileName": "示例成绩单.pdf",
    "uploadedAt": "2026-06-07T01:00:00",
    "parsed": true
  }
}
```

### 3.2 学业概览接口

- 路径：`GET /academic/status`

当前返回重点字段：

```json
{
  "success": true,
  "message": "操作成功",
  "data": {
    "transcript": {
      "fileId": "file-1234abcd",
      "fileName": "示例成绩单.pdf",
      "uploadedAt": "2026-06-07T01:00:00",
      "parsed": true
    },
    "totalCredits": 31,
    "earnedCredits": 20,
    "gapCredits": 11,
    "riskCount": 4,
    "metricLabel": "课程要求单元",
    "preciseCredits": false
  }
}
```

字段说明：

- `metricLabel`
  - 若为 `学分`，表示培养方案有精确学分
  - 若为 `课程要求单元`，表示当前是按课程规则估算，不是精确学分
- `preciseCredits`
  - `true` 表示可按学分理解
  - `false` 表示只能按规则单元理解

### 3.3 学业分析接口

- 路径：`GET /academic/analysis`

当前返回重点字段：

```json
{
  "success": true,
  "message": "操作成功",
  "data": {
    "transcript": {},
    "metricLabel": "课程要求单元",
    "preciseCredits": false,
    "totalCredits": 31,
    "earnedCredits": 20,
    "gapCredits": 11,
    "modules": [],
    "missingRequiredCourses": [],
    "unfinishedGroups": [],
    "recommendedCourses": [],
    "semesterContext": {
      "currentDate": "2026-06-07",
      "currentTermCode": "SPRING",
      "currentLabel": "2025-2026学年春季学期",
      "nextTermCode": "AUTUMN",
      "nextLabel": "2026-2027学年秋季学期"
    },
    "matchedCourseCount": 20,
    "unmatchedTranscriptCourses": [],
    "risks": [],
    "suggestions": []
  }
}
```

建议前端优先消费的字段：

- 现有页面已在使用：
  - `totalCredits`
  - `earnedCredits`
  - `gapCredits`
  - `modules`
  - `missingRequiredCourses`
  - `risks`
  - `suggestions`
- 若后续想增强页面，可继续使用：
  - `metricLabel`
  - `preciseCredits`
  - `unfinishedGroups`
  - `recommendedCourses`
  - `semesterContext`
  - `matchedCourseCount`
  - `unmatchedTranscriptCourses`

## 4. 推荐的小程序改动

当前小程序页面即使不改，也能继续工作，因为旧字段都保留了。

如果要把学业分析页做得更完整，建议新增以下展示：

1. 在概览页显示 `metricLabel`
   - 当 `preciseCredits=false` 时，提示“当前结果按课程规则估算”
2. 在结果页新增“当前学期建议选课”
   - 直接展示 `recommendedCourses`
3. 在结果页新增“未满足的范围选课规则”
   - 直接展示 `unfinishedGroups`
4. 若 `unmatchedTranscriptCourses` 不为空，提示学生或老师补充课程映射

## 6. 已知限制

1. 当前 PDF 解析依赖文本可提取，不支持扫描版 PDF
2. 样例培养方案没有学分列，所以当前主要输出“规则完成度”，不是严格学分审计
3. 成绩单课程名与培养方案课程名仍是字符串匹配，后续最好补一张课程别名映射表
4. 完整 `./mvnw test` 仍会受到仓库内其它依赖数据库的集成测试影响，本次主要验证了新增学业分析单测
